Hey! I'm Ravat, a backend engineer who mostly writes Java and likes making tools that get out of the way.

I've spent a lot of my time on reactive, event-driven services. Most of what I know about them I learned by building on Vert.x and RxJava and digging into the parts that break, like service proxy codegen.

I also look for security bugs in tools I use every day. For px0, a browser IDE for reviewing code, I reported an unsigned self-update, an XSS through /api/raw, and a missing Content-Security-Policy, and sent patches for the last two. All three are fixed upstream.

On my own machine I run Omarchy (Arch + Hyprland) and build plugins for it, like System Pulse and Cloudflare WARP.

You can find everything I've made on the projects page.
