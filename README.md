# Coding-Sparrow.github.io

Personal site of Ravat Tailor, live at https://coding-sparrow.github.io.

Plain HTML, CSS and JS with no build step, styled after [antfu.me](https://antfu.me).

- `index.html` - about page
- `projects.html` - project list, grouped by theme (star counts load from the GitHub API)
- `main.js` - theme toggle and the generative "plum" branch background
- `style.css` - light and dark themes

Preview locally with `python -m http.server` and open http://localhost:8000.
